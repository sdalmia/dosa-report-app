Where these figures come from

Posist reads data/store_health/posist_daily.csv. One row per store per date. The store column is the Posist deployment label. Money is rupees, including values written with thousands separators. A blank cell stays blank.

{{ posist_columns|join(", ") }}

Menu mix is not on file. The command centre only links out to Posist Insights. This repo has no item sales file, so share, quantity, and item net are not listed.

The calendar reads data/store_health/sales_pred_vs_actual.csv. A network file uses the same columns without store. A store calendar adds store. Low, mid, and high on this drop are that store's share of the network judgment band, not a separate model. A day keeps the calendar file's actual when that cell has a figure, including zero. Otherwise it uses that day's Posist net, or gross when net is blank. Predictions and variance stay blank unless the calendar file has them. A blank is not zero. Status may be share_of_network_band or not_on_deployment_report, as well as pending, actual, or actual_provisional_eod.

{{ calendar_columns|join(", ") }}

Keka reads data/store_health/keka.csv. Headcount is registered employees, not people on shift. Primary lead is the largest reporting line, not a confirmed single store manager. The row joins the Posist label in posist_store. A shorter label is used only when it matches one store. Match status is shown as written, including inferred and no keka match.

{{ keka_columns|join(", ") }}

Mystery audit reads data/store_health/mystery_audit.csv. Scores stay as written. A store with no row stays empty. The Brand row is the brand aggregate, not that store's score.

{{ audit_columns|join(", ") }}

Reelo reads data/store_health/reelo.csv. The window on this drop is Last 30 Days, 03 Sep 2026 to 03 Oct 2026. Phone capture is valid visits / (valid + blocked) x 100. A shorter posist_store label joins only when it matches one store. Match status not in Reelo is shown as those words. inferred is not a confirmed address match.

{{ reelo_columns|join(", ") }}

Famepilot reads data/store_health/famepilot.csv. Public rating and public review count are one pair. Private rating, private review count, and overall reviews are shown when the cell has a value. A tie in main threat is shown in full. The capture used the Past 30 days preset; the dates printed on screen were 26 Sep 26 - 02 Oct 26 (7 days), which is not a verified 30-day range. A blank location is no Famepilot location, and the rating stays blank.

{{ famepilot_columns|join(", ") }}
